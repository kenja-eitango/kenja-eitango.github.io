ホームプライバシーポリシー利用規約

プライバシーポリシー

最終更新日: 2026 年 10 月 20 日

1. 対象

本ポリシーは、「賢者の英単語」チャンネルの運営者（以下「運営者」）が使用する Google OAuth アプリケーション 「DragonTOEIC」（以下「本アプリ」）に適用されます。本アプリは運営者が自身の YouTube チャンネルを管理するための 内部ツールであり、第三者に提供されるサービスではありません。

2. 取得する Google ユーザーデータ

本アプリは、運営者本人の Google アカウントの同意に基づき、以下の範囲でのみ Google API にアクセスします。

  • YouTube Data API: 運営者のチャンネルへの動画のアップロードと公開設定、動画情報の取得
  • YouTube Analytics API: 運営者のチャンネルの再生数・視聴維持率などの統計の取得
  • Google Sheets API: 運営者が所有するスプレッドシートへの投稿記録・統計の書き込み

3. 利用目的

取得したデータは、動画の予約投稿、投稿記録の管理、再生データの集計にのみ使用します。

4. 保存と共有

認証トークンは運営者のローカル環境に保存され、第三者に共有・販売・譲渡することはありません。 取得した統計データは運営者が所有する Google スプレッドシートに保存されます。 本アプリは一般ユーザーの個人情報を収集しません。

5. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から取得した情報の使用は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

6. お問い合わせ

本ポリシーに関するお問い合わせは、YouTube チャンネルの概要欄に記載の連絡先までお願いします。
